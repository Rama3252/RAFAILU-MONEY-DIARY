RAFAILU'S MONEY DIARY
=====================
Fungua index.html kuanza.

INSTALL KWENYE SIMU (PWA):
- Ili iwe kama app, host folder hii kwenye website yenye HTTPS (mfano GitHub Pages), kisha fungua kwenye Chrome.
- Chagua "Add to Home screen" / "Install app".
- Data huhifadhiwa kwenye kifaa (browser storage). Tumia Backup mara kwa mara.

FEATURES:
- Graph ya mapato na matumizi
- PIN ya kuingia
- Profile
- Voice-to-text
- Mapato + matumizi + salio
- Orodha ya miamala
- Ripoti
- Backup/Restore
- Export CSV
- Save/Print PDF
- Mobile app-style navigation
- Navigation Home/Miamala/Ripoti/Settings bila kulazimika kusave kila kubadilisha sehemu
